# NSV Vim

Filetype detection and rudimentary highlighting for the [NSV (Newline-Separated Values)](https://nsv-format.org) format.

## Installation

Neovim 0.12+:

```lua
vim.pack.add({ 'https://github.com/nsv-format/nsv-vim' })
```

Vim:

```sh
git clone https://github.com/nsv-format/nsv-vim ~/.vim/pack/nsv-format/start/nsv-vim
```
